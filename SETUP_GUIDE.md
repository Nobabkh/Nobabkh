### Step 2: Add Remote and Push

Run these commands in your terminal:

```bash
cd /home/nobab/Nobabkh

# Add the remote repository (replace with your GitHub username)
git remote add origin git@github.com:NobabKh/Nobabkh.git

# Verify the remote was added
git remote -v

# Push to GitHub
git push -u origin main
```

## 🔧 Customization Tips

### Add More Projects
Edit `README.md` and add new project sections following the same format:

```markdown
### 🚀 Your Project Name
**Short Description**
<div align="center">
  <img src="status-badge-url" alt="Status" />
  <img src="stack-badge-url" alt="Stack" />
</div>

**Key Features:**
- Feature 1
- Feature 2
- Feature 3

**Tech Stack:** Tech1, Tech2, Tech3
```

### Update Contact Info
Edit the contact section at the bottom of `README.md`:

```markdown
<a href="mailto:your-email@example.com">
  <img src="email-badge-url" alt="Email" />
</a>
```

### Add Real Project Links
Replace project descriptions with actual repository links:

```markdown
<a href="https://github.com/your-username/project-name">
  <img src="https://img.shields.io/badge/GitHub-View%20Code-black?style=for-the-badge&logo=github" alt="GitHub" />
</a>
```
